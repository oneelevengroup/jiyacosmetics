# 🖼️ Placeholder & Asset Swap List

Running list of every image/asset that currently uses **stock or placeholder**
imagery and needs to be replaced with real JIYA assets later.

All images are registered in [`src/lib/images.ts`](src/lib/images.ts). To swap one:

1. Add the real file to the documented path under `/public/images/...`.
2. In `src/lib/images.ts`, set that entry's `src` to the local path and `placeholder: false`.

No component code needs to change — everything references images by logical key.
